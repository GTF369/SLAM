# 眉弓曲率标定实验方案

## 目标

估计不同眉区中，照片上的二维长度与皮肤表面长度之间的经验关系，并评估该关系在不同顾客、左右侧和眉区之间的变化。此实验不应把单张照片中的深度估计当成实测三维几何。

## 1. 统一测量定义

每个测量都必须使用同一对明确标记的端点。

- 表面弧长 (s)：沿皮肤表面、沿预先约定的眉区线测得的距离。
- 弦长 (c)：同一对端点之间的三维直线距离。如果只能用平面照片像素，不可把像素距离直接当成毫米弦长。
- 长度修正系数：(k=s/c)，理论上不小于 1。
- 局部圆弧半径：只有在局部圆弧近似合理时，才能从 (s) 与 (c) 解出近似半径。眉弓是三维曲面，不应把这个半径称为完整的解剖曲率半径。

应用中的部位分别为左眉头、左眉身、左眉峰、左眉尾、右眉头、右眉身、右眉峰、右眉尾。记录时需要遵循顾客的解剖学左右侧，不要把自拍预览的屏幕左右直接当作顾客左右。

## 2. 采集控制

1. 先告知顾客测量目的、数据用途、保存方式和退出方式，取得适当授权。仅用随机匿名编号，不记录姓名、电话或预约号。
2. 统一头部姿态、表情、相机距离、焦距、光线和照片取景。双眼尽量平行于图像水平线，避免广角近距离拍摄。
3. 为每一眉区明确端点，并在同一测量流程中先量弦长，再沿皮肤表面量弧长。
4. 每位顾客、每个区域至少重复测量 3 次。记录所有原始读数、测量工具、测量人员、时间和异常情况，不要只保留最后一个数。
5. 同一顾客重复采集必须复用同一匿名顾客编号。重复测量不能当作新的独立顾客。
6. 若顾客有明显头部旋转、皮肤拉伸、测量端点不一致或测量工具打滑，标记为无效并重测。

## 3. 数据分析

应用导出的 CSV 包含每条读数的匿名 case_id、部位、弧长、弦长、系数，以及可用时的局部圆弧半径估计。运行：

```bash
python -m pip install -r ml/requirements.txt
python ml/analyze_curvature.py /path/to/brow_curvature_calibration.csv --output curvature_summary.csv
```

分析报告按部位输出原始测量数、独立匿名顾客数、先在每位顾客内部平均后的系数均值/中位数、顾客层面的 P10–P90 经验区间、顾客层面观察极值，以及先在顾客内平均后再做的 bootstrap 均值置信区间。P10–P90 是样本顾客分布的描述性区间，不是未来顾客的保证范围，也不是单个顾客曲率误差的预测区间。均值置信区间描述人群均值估计的不确定性，不能替代个体预测区间。老版本 CSV 若缺少 case_id，无法可靠进行顾客层面的聚类分析，输出会警告这种限制。

## 4. 建议的研究门槛

- 初步可行性阶段：先采集至少 30 位不同顾客，用于检查测量流程、重复性和数据质量，不能作为最终通用区间。
- 正式建模阶段：根据预期区间宽度、顾客异质性和测量误差事先设计样本量，尽可能覆盖不同脸型与眉形，并安排独立的顾客级验证样本。
- 应单独报告测量人员间一致性、同一人员重复测量一致性、每个部位的有效样本数和无效测量率。
- 最终上线前，应在未参与区间拟合的顾客上进行前瞻性验证，并验证打印后真实尺寸和拓描位置偏差。

## 5. 关于应用修正

当前应用可以收集实测读数并估计局部圆弧半径，但不会自动把所有区域统一乘上一个固定系数，也不会根据单张照片假装重建出真实三维曲面。只有在独立数据支持某个区域的修正方法、验证误差和适用边界之后，才能把该方法写入打印流程。打印后还必须测量 20 mm 校准方框，排除打印机缩放误差。
