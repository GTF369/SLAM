# 口令保护的跨设备案例备份

## 目的与边界

本机案例库原本使用 Android Keystore 中不可导出的设备密钥进行 AES-GCM 加密。不能通过复制私有目录把案例直接迁移到另一台手机。可移植备份用于用户明确选择的单个案例，允许在导出时设置独立口令，在另一台设备输入该口令后恢复案例。

此功能不使用云服务，不上传照片，也不会导出 Android Keystore 密钥。口令不保存在应用中。忘记口令、丢失备份文件或备份损坏时，应用无法代为恢复。备份文件仍含有完整人脸照片及眉形设计信息，虽然经过强加密，仍应按敏感资料管理。

## 在应用中使用

1. 先在“本机案例库”保存当前设计。导出只包含案例库中最近保存的版本；尚未保存的编辑不会自动加入。
2. 点击“导出加密案例”，选择已保存案例。
3. 设置不少于 12 个字符的独立口令，再次确认口令，并确认已获得顾客对备份的明确授权。
4. 在系统文件选择器中选定保存位置。应用不会将口令或案例上传服务器。
5. 在新手机安装兼容版本的眉形设计助手，点击“导入加密案例”，选择备份文件，输入同一口令并确认已取得导入授权。
6. 导入时会验证加密认证、清单、ZIP 路径和图像尺寸。成功后，案例文件会以新设备自己的 Keystore 密钥重新加密，可从“案例库”打开。

不要把备份文件与口令放在同一个没有访问控制的位置。不要使用姓名、手机号或预约号作为匿名案例编号。备份不会因应用内“清除本机记录”而自动删除，因为备份文件位于用户自行选择的位置。

## 格式与安全属性

- 容器魔数：BROWPORT1。
- 密钥派生：PBKDF2-HMAC-SHA256，210,000 次迭代，随机 16 字节盐值。
- 加密：AES-256-GCM，随机 12 字节 IV，128 位认证标签。
- 清单和图片/掩膜文件仅在内存中组装 ZIP，随后对整个 ZIP 加密。备份不会在临时目录写出明文照片或明文 ZIP。
- 导出清单的相对路径只允许案例自身的文件名，不允许路径穿越。导入限制文件数、压缩后/解压后总尺寸、清单尺寸和图像像素数。
- 导入后每个案例资源重新使用 Android Keystore 加密；原设备密钥不会被导出。
- 加密标签可检测口令错误和密文篡改，但不能阻止用户丢失口令、删除文件或误把旧版本备份恢复覆盖为另一份内容。

## 自动化验证

Android 仪器测试验证备份加密/解密往返、错误口令拒绝、密文篡改拒绝、清单路径穿越拒绝和 ZIP 条目路径穿越拒绝。模拟器测试不能替代不同实际设备间的备份/恢复验收。

合并或日常使用前仍需要在两台实际 Android 设备间完成一次受控往返测试，确认恢复后的原始照片、两侧眉区掩膜、多个保存方案、参数和案例显示名称均可正确打开。还应测试储存空间不足、用户取消系统文件选择器、重复导入以及大案例内存占用。该格式不是云同步或自动备份服务。
