# 实体拓印误差验证流程

本流程用于评价“照片中设计的眉形”在 1:1 打印后，映射到顾客真实眉弓时的长度和定位误差。它与照片上的关键点检测、ONNX 推理及打印机纸面比例校准不同。软件测试通过不代表实体拓印误差合格。

## 1. 固定打印条件

每次测试必须记录应用里的打印配置名称，并确保名称唯一对应一组确定的打印机、驱动、纸张、纸张方向、打印质量和缩放设置。切换其中任一设置，视为新配置并重新测量 20 mm 校准框。打印时选择 A4 与 100% / 实际尺寸，关闭“适合页面”等缩放选项。

打印后量取 20 mm 方框两个方向的边长并记录。若其误差超出预先规定的容许范围，不继续评估该张模板的转印误差，应先校准纸面比例。

## 2. 统一端点与测量定义

对以下八个区域分别记录。左/右是顾客的解剖学左右，不是镜像预览画面的左右。

- 左眉头、左眉身、左眉峰、左眉尾
- 右眉头、右眉身、右眉峰、右眉尾

每个区域必须在照片设计、皮肤测量和打印模板中使用同一对明确端点。

- **皮肤表面弧长**：用柔性尺沿眉弓表面约定路径测量，单位毫米。
- **打印模板路径长度**：沿打印模板中同一对端点的轮廓路径测量，单位毫米，不要用整段直线代替弧线路径。
- **端点定位误差**：将模板实际转印后，估计两个对应端点的最大偏离距离，单位毫米。若未测量，留空，不能记为零。
- **打印配置修正系数**：记录应用对该打印配置使用的整体缩放系数。

先对皮肤和纸面比例进行记录，再把模板用于皮肤转印。不要在顾客皮肤上做任何不可逆操作来验证算法。转印位置检查只应用于获授权、适当且符合门店操作规范的测试流程。

## 3. 记录与隐私

应用中打开“转印误差记录”，为每条记录选择打印配置和眉区，填写表面弧长、模板路径长度和可选端点偏差，并选择实际使用的曲率修正方式。记录只包含匿名案例编号和几何测量，不自动附加人脸照片。取得相应授权后，点击“导出转印验证 CSV”。

同一顾客的多次测量必须沿用同一个随机匿名案例编号。不要填写姓名、手机号、预约号或其他身份信息。请单独记录测量人员、测量工具、日期和异常情况；CSV 本身仅包含应用支持的字段时，可用外部合规的实验登记表补充这些非身份研究元数据。

## 4. 分析

描述性分析：

```bash
python ml/analyze_stencil_transfer.py brow_transfer_validation.csv \\
  --output stencil_transfer_summary.csv
```

若要运行预先指定的工程筛查，必须同时提供两个容许误差阈值：

```bash
python ml/analyze_stencil_transfer.py brow_transfer_validation.csv \\
  --min-cases 30 \\
  --max-p90-abs-length-error-mm <预先确定的长度误差阈值> \\
  --max-p90-endpoint-error-mm <预先确定的端点误差阈值> \\
  --output stencil_transfer_summary.csv
```

脚本先把同一匿名顾客、同一打印配置、同一眉区的重复记录汇总为顾客级数据，再计算平均偏差、绝对误差分位数、端点误差覆盖率和人群均值 bootstrap 置信区间。这样可以避免测量次数更多的顾客过度支配统计结果。

样本数量门槛与误差阈值需要在查看最终测试结果前，由专业操作者按预期用途和风险预先确定。文档中的示例数值不构成医疗、行业或临床标准。即使通过工程筛查，也只代表可以交由专业人员审核，不会自动打开应用里的任何补偿功能。

## 5. 上线前不可省略的验证

- 评估测量人员内、测量人员间的重复性和无效测量率。
- 每个打印配置和每个眉区报告独立顾客数量、误差区间和端点定位误差。
- 用没有参与任何阈值选择和修正设计的新顾客做独立验证。
- 若需要判断三维曲面补偿，必须使用独立 3D / 物理参考并评价真实表面路径误差，不能用 MediaPipe 相对 z 代替。
- 在 OPPO Find X7 与指定打印机、纸张和驱动组合上完成端到端验收。
- 在未达到预先确定的误差标准前，保持自动三维曲率补偿关闭。该分析器不会生成可直接用于应用的修正系数。
