# 公开肖像眉形适配压力测试记录

**实验日期：2026-10-28**  
**自动化运行：** [GitHub Actions run #1](https://github.com/GTF369/SLAM/actions/runs/40654228161)  
**脚本：** `ml/public_image_brow_benchmark.py`  
**范围：** A 的候选排序稳定性、B 的相对深度补偿敏感度与圆弧几何敏感度。

## 实验数据与方法

自动化流程从 Wikimedia Commons 下载了 5 张有明确来源及许可标注的成年肖像照片，MediaPipe Face Landmarker 在 5 张图上均检测到人脸关键点。每张图片保留原图，并生成 13 个受控扰动版本，共 14 次检测/排序，包括亮度、对比度、轻微旋转、缩放、伽马、模糊和裁剪。它们是同一张照片的重复技术测试，不是 14 位独立顾客。

A 沿用应用当前的几何规则，对自然款、柔和款、立体款候选打分。报告还把分数经过温度为 5 的 softmax 变换，得到合计为 100% 的**规则参考权重**。温度是人为选定的缩放参数，权重没有用顾客偏好标签校准，因此不是顾客喜欢某款眉形的概率。

B 一方面复现应用现有的 MediaPipe 相对 z 比值，观察它在扰动图片中的变化；另一方面计算半径 15–60 mm、弦长 4–20 mm 的理想圆弧 `arc/chord` 系数网格。这些半径和弦长是人为指定的假设场景，不是从照片中测得的真实皮肤曲面。

## A：候选排序实验结果

| 指标 | 结果 |
|---|---:|
| 下载照片数 | 5 |
| 成功检测到人脸关键点的照片数 | 5 / 5 |
| 每张图片的原图及扰动版本 | 14 次 |
| 当前几何规则的首选款式 | 立体款，5 / 5 张 |
| 首选款式对轻微图片扰动的平均稳定率 | 97.1% |
| 单张照片的最低稳定率 | 85.7% |

5 张测试照片上的平均规则参考权重如下。

| 候选眉形 | 平均规则参考权重 | 单张照片范围 |
|---|---:|---:|
| 自然款 | 31.7% | 23.9%–37.5% |
| 柔和款 | 19.3% | 15.2%–21.6% |
| 立体款 | 49.0% | 41.8%–60.9% |

**重要解释：** 立体款在这个小型便利样本中 5 次都排名第一，说明现有几何启发式在这些脸型特征上偏向立体款。97.1% 表示排序对轻微图像变化相对稳定，不表示 97.1% 的顾客会喜欢首选结果。一个规则可以很稳定，却仍然系统性偏向某一类候选。

因此，这次实验能检查工程行为及暴露启发式偏差，不能完成“真实适配概率”训练。它也不能替代不同脸型、拍摄条件和真实顾客选择的独立验证。

## B：曲率补偿敏感度实验结果

### MediaPipe 相对深度因子

脚本在五张照片及其扰动版本上，按现有应用逻辑计算八个眉区的相对深度因子。尾部区域多次触及应用中的 1.4 上限：

| 眉区 | 相对深度计算触及 1.4 上限的次数 |
|---|---:|
| 左眉尾 | 58 / 70 |
| 右眉尾 | 35 / 70 |
| 左眉峰 | 3 / 70 |
| 其他五个眉区 | 0 / 70 |

这里的 70 指 5 张照片 × 每张 14 个图像版本。这个上限触及频率不是“真实曲率达到上限的概率”，而是当前算法在这批图像上输出被截断的频率。它表明相对 z 估计在眉尾可能容易触及人为上限，不能直接视为毫米级弧长补偿值。

### 理想圆弧情景网格

在 56 组假设弦长/半径组合下，理论弧长与弦长之比为：

| 指标 | 弧长/弦长系数 |
|---|---:|
| 最小值 | 1.00019 |
| 情景网格 P10 | 1.00074 |
| 中位数 | 1.00469 |
| 情景网格 P90 | 1.02879 |
| 最大值 | 1.09459 |

该网格中位数对应约 0.47% 的额外路径长度，P90 对应约 2.88%，最大情景约 9.46%。这些数值仅用于说明圆弧系数对假设参数的敏感性，不是实际人脸的误差区间，也不能证明打印或转印会有相应精度。

真正完成 B 仍需要已标定的三维表面或可靠的多视角/实测参考、重复测量的一致性评估，以及独立顾客上的打印和转印端点误差验证。

## 结论与当前使用边界

1. 已完成：公开肖像下载与归因、候选眉形参数化渲染、几何规则权重、图像扰动排名稳定性计算、相对 z 因子敏感度统计、假设圆弧补偿系数分析。
2. 尚未完成：真实顾客偏好概率、基于真实偏好标签的校准、真实毫米级三维眉弓重建、OPPO Find X7 与指定打印机的实体转印验收。
3. 当前 APK 不应显示或宣称上述参考权重为真实顾客偏好概率。MediaPipe 相对深度补偿应继续保持实验性且默认关闭。
4. 这些照片是小型公开便利样本，不代表目标顾客总体；照片的可用性和版权许可并不自动等于被摄者对所有商业或美容用途的认可。

## 可复现实验文件

运行结果的 CSV/JSON 由 [GitHub Actions run #1](https://github.com/GTF369/SLAM/actions/runs/40654228161) 的 `public-image-brow-experiment-report` 工件提供。工件仅包含数值报告与归因信息，不包含导出的肖像及眉形编辑图像。

图片来源及许可见同一工件中的 `ATTRIBUTION.txt`。该实验不会把公共肖像复制到仓库，也不会用它们生成顾客训练标签。
