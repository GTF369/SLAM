# 眉形设计助手 v0.9.4 自用指南

## 安装

本版面向 OPPO Find X7 等 ARM64 Android 手机。APK 来自 GitHub Actions 构建，仍属于 debug 自用包，不是经过正式签名和门店验收的商业发布版。

1. 将 `BrowDesignAssistant-v0.9.4-ARM64.apk` 下载到手机。
2. 在文件管理器中点开 APK。按 Android/ColorOS 提示临时允许此来源安装，然后完成安装。
3. 首次启动允许摄像头权限。若手机保留了旧版且提示签名不一致，请先导出需要留存的图片/CSV，再卸载旧版后安装新版。卸载会清除应用内部的匿名偏好和曲率记录。
4. 开始前确认手机横竖屏、面部距离、光线和打印机配置适合测试。

## 推荐使用流程

1. **取得顾客同意。** 先说明本地拍摄、效果预览保存、偏好/曲率数据记录、原始照片导出和模型训练用途。不同用途需要相应授权。不要未经同意把顾客原始照片导出作为训练素材。
2. **拍照设计。** 让顾客正视镜头，尽量保持头部水平，避免近距离广角。按界面提示检查对焦、脸部大小和位置。
3. **核验原生眉区。** 点击“识别原生眉区”，仔细检查绿色覆盖层是否只覆盖真实眉毛。需要时手工补画或擦除。掩膜质量提示是基于像素的工程分数，不是模型置信概率。确认后再使用原生眉形底稿。
4. **生成与调整候选。** 选择自然款、柔和款或立体款，再调整粗细、长度、弧度。渐变可暂停/继续，回撤可恢复上一操作。把需要保留的状态分别保存为方案。
5. **比较并留档。** 使用“方案对比”并让顾客选择。可以保存当前效果图，或使用“导出方案册 PDF”导出已保存的多方案对比文件。PDF含可识别人脸的效果图，只能在已取得相应授权后保存、分享或打印。
6. **1:1 拓描打印。** 先量取瞳距实际毫米值。首次打印先不要输入旧打印校准值，选择 A4、实际尺寸/100%，关闭“适合页面”等自动缩放。打印后测量 PDF 上的 20 mm 校准方框，后续仅在打印机、纸张和打印设置保持一致时沿用校准系数。
7. **曲率实测。** 只有在能够可靠测量皮肤表面弧长和同段端点距离时才记录区域数据。单张正面照片和 MediaPipe 相对深度都不能给出真实毫米级三维曲面。区域修正仍属实验性，首次实际顾客使用不建议开启。
8. **偏好数据。** 在“匿名案例编号”中用随机编号关联同一顾客的多套评分和重复测量。不要使用姓名、手机号、预约号等个人信息。只在取得同意后采集反馈，定期通过应用内功能导出或清理本地记录。

## 方案册 PDF 的内容与边界

- 保存当前已保存方案的效果预览、方案名称、风格、粗细、长度和弧度参数。
- 多于四个候选时自动分页。
- 方案册明确标注为沟通用效果预览，不是按真实物理尺寸输出的拓描稿。
- PDF 保存在 Android 的 `Downloads/BrowDesign` 目录中。与相册图片、导出的 CSV 一样，清除应用内记录不会自动删除这些外部文件。

## AI 模型当前状态

当前版本没有真实顾客偏好数据训练出的、完成独立验证并被审核通过的推荐模型。默认候选排序使用几何规则参考分，不是经校准的真实概率。眉区分割使用通用人脸解析模型或自适应对比度回退，必须人工检查并修正。

当积累了取得授权的偏好数据后，按仓库 `ml/README.md` 进行顾客级分组、校准和独立验证。不要使用虚构数据训练模型，也不要把内部测试数据当成真实顾客证据。

## 必须留意的安全边界

- 真实顾客照片属于敏感的人脸信息。应用默认在本机处理，不等于文件导出后的分享是安全的。
- 不要将未经校验的打印稿直接用于不可逆操作。不同打印机的缩放、纸张和驱动设置都会影响尺寸。
- 眉区识别、参数推荐和局部曲率修正没有完成完整门店验证。每次均需纹绣师复核。
- v0.9.4 自动构建、Python 测试通过，不等于已经在实际 OPPO Find X7 和实体打印机上完成验证。
- EasyPortrait 模型来源及许可条件见 `docs/MODEL_PROVENANCE.md`。商业使用或转发前应审阅具体上游许可。
