# 眉形设计助手（Android 原型）

本仓库是面向纹绣师的眉形设计、方案比较与打印辅助 Android 原型，优先针对 OPPO Find X7 验证。

## 当前功能

- 使用 CameraX 前置摄像头拍摄高分辨率照片，并在静态照片上重新运行 MediaPipe Face Landmarker，使屏幕预览、设计、比较和打印共用照片坐标。
- 拍摄前显示顾客授权提示，检查照片中脸部大小、居中程度和头部倾斜。
- 生成自然款、柔和款和立体款候选。未安装训练模型时，用可解释的几何规则初排，参考分不是 AI 概率。
- 调整眉形粗细、长度和弧度，支持渐变预览、暂停、回撤、多方案保存、删除和对比。每套方案可保留其自身的原生眉区掩膜，避免对比时误用另一套方案的识别结果。
- 原生眉区预分割支持灵敏度调整、手工补画/擦除，并可切换“原生眉形轮廓底稿”模式，让已编辑掩膜直接驱动预览、对比、效果图和打印描线。默认分割是自适应对比度预分割，尚不是已验证的商用 AI 分割模型。
- 在取得单独授权后，可以导出原始照片做人工标注。仓库含标注工具、轻量分割模型训练脚本、分组验证和候选模型晋级门槛，但不包含训练权重。
- 将当前设计效果图保存到手机相册。
- 通过 Android 打印框架输出眉形轮廓稿，按实测瞳距初步换算物理尺寸，输出前将自拍预览的左右镜像翻回真实方向，并在打印页附 20 mm 校准框。
- 录入左/右眉头、眉身、眉峰和眉尾的实测表面弧长与弦长，计算修正系数与局部圆弧近似半径，保存匿名记录并导出 CSV。只有当前匿名顾客八个区域都已实测时，才可选择把区域长度系数实验性地应用到打印轮廓。
- 收集匿名顾客满意度和方案偏好，导出 CSV。提供按顾客案例分组的训练脚本，在真实数据积累后生成可由应用加载的 `brow_ranker.json`。
- 提供按匿名顾客分组的曲率区间分析、圆弧半径描述统计、bootstrap 置信区间脚本和 Python CI 测试。

## 运行与构建

每次推送到 `main` 分支都会触发 GitHub Actions。打开 **Actions → Build Android APK**，进入最新成功的工作流，下载 `face-pattern-oppo-debug-apk` 工件。

本地构建需要 JDK 17、Gradle 8.13、Android Gradle Plugin 8.13.0 和 Android SDK Platform 36，执行：

```bash
gradle --no-daemon assembleDebug
```

## 产品化状态

当前版本为 target API 36 的调试原型，尚不应宣传为已完成商业验证的产品。项目包含模型训练与模型接入流程，但没有真实顾客反馈训练出的排序模型，也没有真实标注训练出的分割权重。原生眉区的自适应掩膜可作为人工修正起点，不能等同精准 AI 分割。三维眉弓校正目前是用户实测数据驱动的实验性区域长度修正，不是三维重建。正式发布还需要授权数据、独立验证、OPPO Find X7 与目标打印机实测、运营者签名密钥和隐私政策审核。
## 重要限制

1. 目前没有基于真实顾客反馈训练的模型文件，因此默认结果是几何启发式参考分，不是经校准的概率，也不应被描述为已验证的“最适合眉形”。必须先获得顾客授权，采集多个候选的满意度，再按 `ml/README.md` 训练并进行独立验证。
2. 应用能从原生眉区掩膜提取描线轮廓并支持人工补画/擦除。若未训练模型存在，系统用启发式自适应对比度算法产生初始掩膜。该结果可能把阴影/眉妆误识别为眉毛，也可能漏掉浅色眉毛，尚未完成毛流识别与独立准确率验证。输出必须由专业纹绣师确认。
3. 单张正面照片不能唯一恢复眉弓真实三维曲率。当前应用只使用顾客实测弧长/弦长系数做实验性区域长度修正，未自动重建个体三维曲面，也未在实物转印结果中验证修正精度。
4. 1:1 输出依赖实测瞳距、拍摄透视、打印服务和打印机设置。必须打印后实测 20 mm 校准框，确认尺寸无误后再用于拓描。不同打印机的真实输出尚未全部验证。
5. 当前仍是调试原型，尚未完成 OPPO Find X7 真机全流程验证、门店可用性验证、独立 AI 模型验证或正式发布签名。不可将未经校验的打印稿直接用于不可逆纹绣操作。

## 曲率标定建议

完整测量方法、匿名编号、重复测量和验证建议见 [ml/CURVATURE_PROTOCOL.md](ml/CURVATURE_PROTOCOL.md)。


同一局部段需要同时测得皮肤表面弧长与两端直线弦长，修正系数定义为 `k = 表面弧长 / 直线弦长`。按左右眉头、眉身、眉峰、眉尾分区记录。样本 10%–90% 分位是当前测量样本的描述统计，不是保证适用于所有顾客的解剖边界。正式确定区间前，应建立统一测量协议、重复性评估和独立验证集。

## 隐私与安全

原型不把照片上传服务器。拍摄前会提示取得顾客同意，照片用于本机内存中的设计与打印。保存效果图会将含人脸的图片写入相册。匿名偏好和曲率记录保存在应用内，可导出 CSV，也可用应用内按钮清除。已导出的 CSV 和相册图片需要用户另行删除。正式版本仍需要完成隐私告知、权限审查、安全评估、数据保留政策和更完整的案件管理。
